Firmware flashen

  1. ESP32‑C5 per USB‑C-Datenkabel an den Computer anschließen. Chrome oder Edge verwenden.

  2. Im Fenster „USB JTAG/serial debug unit“ wählen. Dauert etwa eine Minute. Wird kein Gerät angezeigt, beim Einstecken die BOOT-Taste halten.

  3. In der App auf Verbinden tippen und diesen Code eingeben:

    666666

    Den Code kann man danach in der App unter Einstellungen ändern.
